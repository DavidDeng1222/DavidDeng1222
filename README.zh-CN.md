## 代表项目

### [Motus — 羽毛球动作研究与回放工具](https://github.com/DavidDeng1222/motus-showcase)

一个以本地处理为优先的 SwiftUI 原型，将原始视频、2D 姿态证据、选定运动员的 3D 回放与球拍方向研究整合到同一条时间线上。

- 最近一次记录的测试包含 38 组测试套件、3,838 项确定性工程检查。
- 通过 AVFoundation、Apple Vision 与 SceneKit 联动实现视频回放、视觉分析和空间呈现。
- 保留失败案例、被拒绝的候选结果，以及显示重建和测量数据各自的来源，作为研究证据。
- 公开仓库提供经过审阅的项目案例；核心算法与原始档案保持私有。

### [Elder-Friendly Offline Games — 适老离线互动游戏](https://github.com/DavidDeng1222/cognitive-wellness-case-study)

一个经过匿名化处理的跨平台产品案例，面向公共服务等候场景中的老年用户。

- 七种休闲小游戏，四档难度。
- 使用 SwiftUI 开发 iOS / iPadOS 版本，使用 Flutter 共享 Android 与 Windows 实现。
- 优先支持离线使用，无需账户、无云端成绩服务，不申请摄像头、麦克风或定位权限。
- 采用大字号、高对比度、宽松的点击区域与温和的反馈。

公开案例不包含机构品牌、私有部署材料或客户专属内容。
